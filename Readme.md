# Nginx training

Учебный проект для тренировки работы с Nginx: установка, управление сервисом,
настройка конфигов.

## Как устроен проект

- В ветке `main` лежит **стенд**: Linux-контейнер (Ubuntu 24.04) с работающим systemd
  и установленным Nginx.
  - `Dockerfile` — образ стенда.
  - `compose.yaml` — запуск контейнера со всеми нужными параметрами.
- Каждое задание — отдельная ветка `task-N-...` с папкой, в которой лежит `README.md` с условием.

| Ветка | Задание |
|---|---|
| `task-1-nginx-setup` | Управление Nginx как systemd-сервисом: start/stop, reload, enable/disable, своя страница |

## Запуск стенда

Нужен Docker Desktop в режиме Linux containers (по умолчанию).

Из корня репозитория:

```powershell
docker compose up -d --build      # собрать образ и запустить контейнер
docker exec -it nginx-train bash  # зайти внутрь
```

Nginx доступен на хосте по адресу http://localhost:8080.

Остановить и удалить стенд:

```powershell
docker compose down
```

## Как работать с заданиями

1. Переключись на ветку задания: `git checkout task-1-nginx-setup`.
2. Прочитай `README.md` в папке задания.
3. Запусти стенд и выполни задание.
4. Запустить тест для проверки.
