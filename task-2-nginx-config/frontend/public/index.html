Задачи

    Как это работает

    Приложение состоит из двух программ в разных контейнерах. Nginx принимает все запросы на todo.localhost и решает, кому их передать:

    /api/…
    бекенд todo-api — хранит задачи. Снаружи порт 5500, внутри контейнера 5000
    всё остальное
    фронтенд todo-web — отдаёт эту страницу. Снаружи порт 3300, внутри контейнера 3000

    Схема сверху показывает, через что на самом деле прошли запросы. Открой localhost:3300 напрямую — страница загрузится, но nginx и API погаснут: без nginx запрос на /api попадает во фронтенд, а тот API не обслуживает.
